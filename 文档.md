# 前端部署交接文档

## 项目信息

- **Git**: https://gitlab.wsimkuajing.in/trx/bot-frontend
- **分支**: refactor-api
- **后端地址**: 127.0.0.1:8888

---

## 前端构建

```bash
cd bot-frontend
pnpm install

# 一键构建管理端和运营端（推荐）
pnpm build:pro

# 或分别构建
pnpm build:management  # 只构建管理端
pnpm build:operation   # 只构建运营端
```

**产物**: `dist-management/` 和 `dist-operation/`

---

## 运维部署

### 1. 上传文件到服务器

```bash
/var/www/bot-frontend/dist-management/
/var/www/bot-frontend/dist-operation/
```

### 2. Nginx 配置

```nginx
server {
    listen 80;
    server_name yourdomain.com;

    # 管理端
    location /management {
        alias /var/www/bot-frontend/dist-management;
        try_files $uri $uri/ /management/index.html;
    }

    # 运营端
    location /operation {
        alias /var/www/bot-frontend/dist-operation;
        try_files $uri $uri/ /operation/index.html;
    }

    # API 代理到后端
    location /v1/ {
        proxy_pass http://127.0.0.1:8888;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /v2/ {
        proxy_pass http://127.0.0.1:8888;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 3. 重载

```bash
sudo nginx -t && sudo systemctl reload nginx
```

## 访问地址

## 说明

- 前后端同服务器，后端 `127.0.0.1:8888`
- API 自动添加版本前缀（管理端 `/v1`，运营端 `/v2`）
- 更新时重新构建上传即可
